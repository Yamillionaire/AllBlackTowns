# All Black Towns

A music project honoring the historic Black towns and neighborhoods of America — one town, one song, one story at a time.

**Live site:** https://yamillionaire.github.io/AllBlackTowns/

## Pages
- `index.html` — Home
- `towns.html` — Searchable index of 128 historic Black towns
- `music.html` — The 148-song catalog
- `about.html` — The mission

## Publishing
Hosted free on GitHub Pages from the `main` branch. To rebuild town data, run `python3 build.py` (reads from the project archive) and push.
